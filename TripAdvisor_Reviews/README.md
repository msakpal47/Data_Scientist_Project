# ReviewInsight AI

Enterprise structure for TripAdvisor_Reviews with BERT embeddings and clustering.

## Install

pip install -r requirements.txt

## Train

python src/train_embeddings.py --algo kmeans --clusters 5

Artifacts are saved under models/. Clustered CSV is saved under data/.

## Run App

python app/app.py

Open http://127.0.0.1:5000 in a browser.

## Alternative Baseline

python src/clean_and_train.py

TF‑IDF + KMeans artifacts saved under models/.
